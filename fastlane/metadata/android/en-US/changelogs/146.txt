New Rotation health screen, in Settings under Diagnostics. When automatic wallpaper change quietly stops there was nothing to look at. The five reasons it can stop all look the same from the home screen, and each needs a different response, so the screen names which one it is: rotation is off, it's waiting its turn, Android is holding it back to save battery, the schedule got dropped after a restart, or the last run failed. It shows when rotation last ran and when it is next due, and there's a Run now button so you can watch one happen instead of guessing. Where the device refuses to answer, it says so rather than showing a plausible-looking value.

Fixed a crash on Android 8.0 when a live wallpaper published its colours. The call that tells the system a wallpaper's colours changed only exists from Android 8.1, and Aura made it on all seven of its publish paths, which crashed the wallpaper service outright on 8.0.

Media playback, image loading and networking libraries all moved up after a toolchain change cleared the blocker they had been stuck behind. Nothing changes on screen. Alongside that, 52 real defects became visible for the first time in a while, because the code checker had been unable to complete a run at all, and those are fixed too.
